# Análisis de reclamos ciudadanos — CABA

> En construcción. El README final se completa en la Fase 6.

**Datos:** [Sistema Único de Atención Ciudadana / BA Colaborativa](https://data.buenosaires.gob.ar/dataset/sistema-unico-atencion-ciudadana)
(Buenos Aires Data, licencia CC-BY-2.5-AR). Se usan los años 2024, 2025 y 2026 (parcial).

**Preguntas de negocio:**
1. ¿Cuántos reclamos entran por mes y cómo evoluciona el volumen?
2. ¿Qué categorías y barrios/comunas concentran más reclamos?
3. ¿Qué tasa de cierre (% cerrado) tiene cada categoría?
4. ¿Qué tasa de cierre (% cerrado) tiene cada comuna?
5. ¿Hay estacionalidad por día de la semana o mes?

> El dataset no publica fecha de cierre, solo el estado (Abierto/Cerrado), por eso
> no se mide el tiempo de resolución y se usa la tasa de cierre en su lugar.
